# 📊 글로벌 증시 마감 요약 대시보드 (Market Briefing)

한국(KRX) 및 미국(US) 정규장이 마감된 후, 당일의 시장 상황과 주요 지표, 수급 및 주도주 동향, 그리고 다가오는 핵심 예정 일정을 균형 잡힌 시각(너무 간략하지도, 지나치게 장황하지도 않은 적절한 깊이)으로 요약해 주는 전문 금융 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **사이드바 증시 전환**:
   - `한국 (KRX)` 🇰🇷 및 `미국 (US)` 🇺🇸 원클릭 전환
   - 시장별 정규 거래 시간 및 당일 마감 상태 뱃지 표시
   - 실시간 데이터 새로고침 및 캐시 갱신 기능

2. **상단 핵심 지표 카드 (Top KPIs)**:
   - **한국**: 코스피, 코스닥, 원/달러 환율, 코스피 외국인 순매수 규모
   - **미국**: S&P 500, 나스닥 종합, 미 국채 10년물 금리, 변동성 지수(VIX)

3. **균형 잡힌 시장 마감 요약 (Balanced Market Summary)**:
   - **⚡ 1분 핵심 총평 3선**: 오늘 하루의 핵심 분위기를 3개 불릿으로 압축
   - **📖 상세 마켓 브리핑**: 지수 흐름, 수급 및 자금 동향, 주요 섹터 및 대형주 움직임 심층 분석

4. **투자 주체별 수급 & 핵심 대형주/메가캡 현황**:
   - **한국**: 개인/외국인/기관 순매매 금액 바 차트 및 코스피 시총 상위 대형주 테이블
   - **미국**: M7(엔비디아, 애플, 마이크로소프트 등 7종목) 등락 테이블 및 7대 글로벌 매크로 지표(필라델피아 반도체, 국채금리, 달러인덱스, 원유, 금, 비트코인, VIX)의 1:1 대칭 시각화

5. **📅 주요 예정 사항 (Upcoming Catalysts)**:
   - FOMC 정례회의, 한국은행 금통위, 미 CPI/고용보고서, 선물옵션 만기일 등 주요 일정 D-Day 카운트다운 및 중요도 뱃지

6. **💡 다음 거래일 핵심 투자 체크포인트**:
   - 투자자가 개장 전 꼭 점검해야 할 핵심 관전 포인트 3가지

7. **📥 원클릭 리포트 다운로드**:
   - 일일 브리핑 내용을 텍스트 파일(.txt)로 즉시 다운로드하거나 복사하여 텔레그램, 메신저 등에 손쉽게 공유 가능

## 🚀 실행 방법

### 방법 1. 원클릭 실행 (Windows)
폴더 내 **`run_app.bat`** 파일을 더블 클릭하면 필요한 패키지 확인 후 자동으로 브라우저에서 대시보드가 열립니다.

### 방법 2. 터미널 수동 실행
```bash
# 1. 패키지 설치
pip install -r requirements.txt

# 2. 앱 실행
streamlit run app.py
```
브라우저에서 `http://localhost:8501` 접속
